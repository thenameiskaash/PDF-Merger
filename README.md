# PDF Merger
A desktop app to drag and drop PDF files and merge them into one.

## Download
Go to Releases and download the latest installer.

## How To Use
1. Download and run the installer
2. Open PDF Merger from Start Menu
3. Drag and drop your PDF files
4. Click Merge
5. Choose where to save your merged PDF

## Note
Windows may show a SmartScreen warning — click More info then Run anyway.
This is normal for unsigned apps.
